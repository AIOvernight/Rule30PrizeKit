# Rule 30 Problem 1: equivalent forms

Rule 30 Prize Problem 1 asks whether the center column of rule 30, started from a single black cell, is ever eventually periodic. It is open. This folder collects statements that are **proved equivalent** to it in Lean 4 + Mathlib. A proof of any one of them is a proof of Problem 1.

```lean
-- the center column read as the binary number 0.c(0)c(1)c(2)…
noncomputable def centerBinary : ℝ := ∑' t, (if c t then 1 else 0) / 2 ^ (t + 1)

theorem problem1_iff_irrational_binary : Rule30Prize.Problem1 ↔ Irrational centerBinary
```

**Status:**
- 51 of the 54 equivalent forms in [CATALOG.md](CATALOG.md) are proved here, as 151 theorems named `problem1_iff_*`.
- For one more form, [41], for the frozen-boundary conjecture, for Prize Problem 3 and for the stronger statements of catalog Section 4, the direction "the statement implies Problem 1" is proved: `problem1_of_*`.
- Prize Problem 2 (density 1/2) is proved equivalent to its limit form, to its Abel-mean form and to the simple normality of x₂ in base 2 (`problem2_iff_tendsto`, `problem2_iff_abel`, `problem2_iff_simplyNormal`); the Abel-mean form needs the Hardy–Littlewood–Karamata Tauberian theorem, proved in Tauberian. Normality gives Problem 2 (`problem2_of_isNormal`).
- Every one uses only `propext`, `Classical.choice` and `Quot.sound`. None uses `sorry` or `native_decide`.
- For each module of the first two batches, an independent verifier recompiled the file, checked its axioms and restated its main theorems. The fifty-five later modules (IntegerRows, LogicAutomata, Realization, WordForms, Expansions, Holonomic, OmegaRegular, PisotBase, Automatic, Transcendence, LempelZiv, CoupledHalves, TailLanguage, TFunction, TFunctionCycles, DFinite, AutomatonGroup, FrozenBoundary, FrozenBoundaryPeriodTwo, FrozenBoundaryCore, Lyndon, Lagrange, Minkowski, GoldenPowers, ContextFree, AlgebraicDFinite, Strassmann, SkolemMahlerLech, DiophantineGraph, NaturalBoundary, Cobham, Christol, OneTapeGap, OfflineGap, MonadicLogic, BuchiArithmetic, LimitPoints, OrderDefinable, ProblemThree, StrongerStatements, AlgebraicDegree, RightHalfReturns, Tauberian, ProblemTwo, BuchiConverse, Odometer, CenterFormulas, OneTapeRegular, UniformMorphic, MeromorphicExtension, TwoAdicPeriods, RegularSequences, PisotNumbers, ProfiniteIntegers and PresburgerExpansion) were compiled and axiom-checked by their author only.

## Building

This is a Lake project on Lean 4.30.0. It pins Mathlib at commit `c5ea00351c` and depends on the core-Lean snapshot in [`../lean`](../lean) for `Rule30Prize.Problem1`.

From the kit root, which shares one Mathlib with this folder:

```sh
lake exe cache get        # prebuilt Mathlib (or sh setup.sh)
lake build                # builds the kit, the catalog and this library; about 1 minute here
lake env lean equivalents/scripts/CheckAxioms.lean   # axioms of all problem1_iff_*, problem1_of_*, problem2_iff_* and problem2_of_* theorems
```

## Adding an equivalent form

1. Pick an entry from [CATALOG.md](CATALOG.md) whose status is *Stated*. Its suggested Lean statement is in the entry.
2. Prove a general theorem for every `b : ℕ → Bool`, then specialize it to `c` as `Rule30Prize.Problem1 ↔ X`.
3. Watch for:
   - double expansions in base 2;
   - eventually constant sequences (`Rule30Prize.center_not_eventually_constant` handles them for c);
   - `0 < P`.
4. Keep the file free of `sorry`, `native_decide` and new axioms. Add it to `Rule30Equivalents.lean`, and regenerate `scripts/CheckAxioms.lean` with `python3 equivalents/scripts/gen_check_axioms.py` from the kit root.
5. Have someone other than the author restate the main theorem from scratch and check that it says what it claims.

The hard classical ones are Szegő and Pólya–Carlson (natural boundary, [41]) and Durand ([46]).
